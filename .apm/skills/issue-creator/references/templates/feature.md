# 機能追加テンプレート

プロジェクトに`.github/ISSUE_TEMPLATE/feature*.md`・`.gitlab/issue_templates/feature*.md`が無い場合に使う。

```markdown
## 概要
[追加したい機能を1行で]

## 動機
[この機能が必要な理由（どんな問題を解決するか、誰のためか）]

## 提案する解決策
[どのような機能であるべきか（UI・API・挙動の概要）]

## 受け入れ条件
- [ ] [完了条件1]
- [ ] [完了条件2]
- [ ] [完了条件3]

## ユースケース
[具体的な使用シナリオ（「ユーザーがXをしてYを得る」のような形式）]

## 検討した代替案
[他に検討した方法と、この方法を選んだ理由（なければ節ごと削除）]

## 関連するコード
[既存コードで関連する箇所があれば記載（コードベースから判明したもののみ）]
- `path/to/related.ts`

## スコープ外
[このIssueで扱わないこと（スコープを明確にするため）]

## 補足情報
[モックアップ・参考実装・関連Issue等]
```

## 節の規則

各節の規則を次に示す。

- 動機は、「あったほうが良いから」では不十分である。具体的な動機をユーザーから聞き出して書く
- 提案する解決策は、確定した設計でなくてよい。方向性が示されていればよい。実装の詳細はPRで議論する
- 受け入れ条件には、完了の判定基準をテスト可能な形で書く
- ユースケースには、抽象的な機能の説明だけでなく、具体的な使用例を含める
- 検討した代替案・スコープ外・補足情報は、該当する情報がない場合は節ごと削除する
